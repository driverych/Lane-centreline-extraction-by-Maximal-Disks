# Data inputs and generated outputs

Keep this directory beside the numbered code modules: their drivers use
relative paths into it. A file present in a private working copy is not
necessarily tracked by Git or available in a public clone.

| Directory | Role |
| --- | --- |
| `mapData` | Input Lanelet2 maps in OSM XML format |
| `LaneletData` | Synthetic boundaries and map-processing intermediate MAT-files |
| `centrelineComparasion` | Generated centreline results; spelling retained for existing paths |

## Jiangsu University demo

`mapData/demo Lanelet2 map.osm` is the demo map captured at Jiangsu University,
as supplied by the project author. It is distinct from the inD/rounD source maps.
Its provenance and redistribution permission should be documented before a
public release includes it; this README does not assign it a new license.

The recommended processing chain produces:

```text
demo Lanelet2 map.osm
  -> originalLanelet_demo.mat / originalMultiPoly_demo.mat
  -> alignedLanelet_demo.mat / laneList_demo.mat / laneList_LaneletID_demo.mat
  -> cnlWithMDP_cnlDiscret_5dm_demo.mat
```

The first two stages are documented in [map extraction](../1_extractLanelets/README.md)
and [lane reconstruction](../2_rebuildLanes/README.md). The final stage is
[centreline calculation](../3_centrelineCalculation/README.md).

## Synthetic data

`LaneletData/laneList_dummy.mat` is generated by
[the synthetic generator](../8_buildDummyLanelist/README.md). It contains ordered
left and right boundaries, in planar metres, and no inD or rounD map data.
`centrelineComparasion/cnlWithMDP_cnlDiscret_5dm_dummy.mat` is a synthetic result
file. Generation and calculation drivers overwrite their selected outputs.

## Private research data

Files named with `locn1` through `locn5` may exist locally for the paper's
experiments. They are excluded from the intended public release under the
project's existing restricted-data policy; see [third-party notices](../THIRD_PARTY_NOTICES.md).
Obtain source datasets from their providers. Review the actual staged file list
before publishing: ignore patterns alone do not establish data provenance or
exclude files that were already committed.
